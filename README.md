# 骨科专科智能规划演示系统

这是依据需求截图中“骨科专科 AI 适配模块”制作的本地演示项目。覆盖脊柱侧弯矫形术前规划、关节置换假体匹配、骨折内固定方案推荐，并串联病例创建、参数校验、影像附件、候选方案、人工复核、审计留痕与可打印报告。

2026 年 10 月 22 日更新：前端已改为 Vue 3，采用浅蓝、薄荷绿、白色与医疗器械插图；增加分维度尺寸偏差、规则计算过程、三场景单因素敏感性分析、方案版本切换及病例搜索筛选。器械目录包含髋、膝各 5 组虚构规格。

## 启动

需要 Python 3.9 或更新版本，后端无第三方依赖。Vue 3.5.44 生产文件和插图已随项目提供，无需 npm、构建步骤或联网加载 CDN。

```powershell
python app.py
```

然后打开 <http://127.0.0.1:8765>。若电脑以 `py` 启动 Python，也可以运行 `py -3 app.py`。关闭终端即可停止服务。

## 操作流程

1. 选择脊柱、关节或创伤场景，输入病例编号和人工确认的测量值。
2. 点击“创建病例并生成方案”；可在详情页上传 PNG/JPEG 影像附件供人工查看。
3. 查看方案排序、规则依据、风险提醒和复核要点。
4. 输入复核人、意见及通过或退回结论，提交后形成审计记录。
5. 点击“导出报告”，用浏览器打印或保存为 PDF。
6. 在详情页点击“生成新版本”，并通过版本下拉框回看历史方案；已复核的旧版不会被新方案覆盖。当前版本功能针对同一份病例测量值重新分析，未提供修改病例参数的功能。

示例输入已预填在界面。病例数据保存在 `data/demo.sqlite3`，影像保存在 `data/uploads/`。需要清空演示数据时，停止服务后删除这两个位置的生成内容即可。

## 架构与接口

- `static/`：Vue 3 模板、响应式交互与 CSS，无构建步骤。
- `static/vendor/`：本地 Vue 3 生产构建与 MIT 许可。
- `static/assets/`：医学器械场景示意插图。
- `app.py`：本地 HTTP API、SQLite 持久化、文件上传、报告导出和审计记录。
- `planner.py`：三类可解释的教学规则与排序模型。
- `tests.py`：11 项测试，覆盖三类场景的闭环、低柔韧性排序、髋膝匹配、输入类型、敏感性、版本保留和静态资源路径。

主要接口：`GET /api/cases`、`POST /api/cases`、`GET /api/cases/{id}`、`POST /api/cases/{id}/image`、`POST /api/cases/{id}/analyze`、`POST /api/plans/{id}/review`、`GET /api/plans/{id}/export`。

## 算法边界

本系统使用虚构器械目录和人工录入测量值。脊柱模块以柔韧性估计示意目标，关节模块按几何尺寸加权差排序，创伤模块用可解释规则排序。分数不是成功率，也未使用临床训练数据。影像附件不参与自动识别。系统未接入医院信息系统、真实器械库、三维重建或生物力学仿真，不可用于诊断、手术决策或医疗器械注册申报。

敏感性分析只改变一个输入并保持其他条件不变，用于理解规则响应，不表示概率或置信区间。附件属于病例，重新上传会替换当前附件；方案结果与复核按版本保留，附件未按方案版本保存历史快照。
