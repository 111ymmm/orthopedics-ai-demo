# 骨科专科辅助规划工作台 v2.0

这是原骨科专科智能规划演示项目的改进版。保留脊柱、关节、创伤三个场景，新增影像四点辅助测量、参数修订、方案版本对比和输入快照追溯，并重做桌面与手机界面。

项目定位为本地教学与研究流程原型。当前仍使用可解释教学规则和虚构器械目录；没有接入经临床训练与验证的自动影像识别模型。

## 启动

需要 Python 3.10 或更新版本。建议使用已安装的标准 Python。

Windows 解压后，双击 **启动工作台.cmd**。启动器会打开本地浏览器；首次缺少 Pillow 时，会在项目目录创建 `.venv` 并安装唯一依赖，因此首次安装需要网络。后续运行服务不需要连接外部网站。

启动脚本会实际验证 Python 能否运行，不再仅凭 `py.exe` 文件存在判断安装成功；也支持 `ORTHO_PYTHON`、项目虚拟环境及本机已有的 Codex Python 运行环境。已运行的服务会直接复用，避免再次启动时报端口占用。可运行 `启动工作台.cmd --check` 检查当前 Python、Pillow 和服务状态。

也可以从终端运行：

```powershell
python -m pip install -r requirements.txt
python app.py --open
```

默认地址为 `http://127.0.0.1:8765`。端口被占用时可指定其他端口：

```powershell
python app.py --port 8766 --open
```

请保持启动命令窗口打开；关闭窗口或按 Ctrl+C 会停止服务，之后访问网址就会显示拒绝连接。浏览器页面本身可以自行关闭。不要在服务使用数据目录时删除数据库。

## 建议体验顺序

1. 在工作总览点击“载入三类演示病例”，创建带明确 DEMO 编号的合成病例；程序不会在启动时自动写入病例。
2. 打开脊柱病例，进入“影像与测量”。上传自己的 PNG/JPEG，或点击“导入测量示意图”。示意图有英文合成标记，不是真实医学影像。
3. 依次点击上端椎终板的两个端点、下端椎终板的两个端点。工具显示两条线的无符号锐角；可以撤销或重选。示意图彩色参考线对应 53.1°。
4. 核查后保存测量，再生成新方案。测量点、影像 ID、原图 SHA256 和角度会保存在方案快照中。
5. 填写复核人、意见并通过或退回。复核结论不可覆盖；当前资料不足或没有候选时只允许退回。
6. 点击“修改参数”，保存并生成新版本。通过版本选择器、历史列表及“版本对比”查看变化。
7. 导出打印报告或 JSON 快照。历史报告使用历史输入，不读取当前修改后的参数。

## 本版变化

- 工作总览使用真实病例计数；病例档案支持编号搜索、场景和状态筛选。
- 脊柱低柔韧性分支统一排序，取消无依据的“顶椎上下若干节段”建议。
- 髋臼杯和股骨柄分别建模，组合显示；髋膝使用各自的测量字段。
- 假体先按演示几何约束筛选，再按原始误差排序；无有效候选时停止首选推荐。
- 骨折骨段和开放情况纳入输入，阶段性处理与最终内固定候选分别展示。
- 输入变更后旧方案成为历史版本，不能误作当前方案复核；重新生成按修订号排序。
- 每份方案保存输入快照、影像引用、规则版本、目录版本及复核信息。
- 影像完整解码并验证格式，按 EXIF 方向生成测量预览，同时保留不可变原文件。
- 上传替换影像时保留旧文件；旧方案仍可查看原来绑定的影像。
- 并发提交复核只允许一个请求成功，避免覆盖结论。

## 数据与旧版兼容

默认数据目录为项目下的 `data/`：

- `demo.sqlite3`：病例、方案、影像索引及操作记录。
- `uploads/`：原始影像及去除元数据、按 EXIF 方向规范化的 PNG 预览。
- `server.log`：本地服务日志。

也可以使用独立数据目录：

```powershell
python app.py --data-dir D:\ortho-demo-data --open
```

打包文件不含测试病例数据库或任何患者数据。升级旧项目时先备份整个旧版 `data/`，再将副本交给新版读取；新版会补齐字段并保留旧记录。旧版未保存的历史输入与影像绑定无法还原，新版会明确标为旧版记录，不会伪造完整追溯信息。旧影像文件不会被删除，需重新上传才能建立新版的可追溯影像索引。旧版髋关节的 `bone_diameter_mm` 字段可作为髋臼直径别名读取；旧版膝关节应补录股骨、胫骨的四项测量。

新版方案快照不可随编辑操作变化；本地文件和 SQLite 本身不是防篡改存储。复核人字段是演示记录，不是医院身份认证或电子签名。

## 图像测量范围

四点工具依赖人工确认端椎、终板线和图像体位。程序按规范化预览的真实宽高计算角度，避免画布缩放或图片长宽比导致误差。显示角度范围为 0–90°，本演示脊柱输入保存范围为 10–90°。不同体位、畸形、投影和影像质量会影响测量；工具未实施 DICOM 标定、自动端椎识别或三维测量。

关节筛选阈值、尺寸差权重及创伤加减分都是教学配置，并非临床阈值。无需为了演示分数接近 100 而修改真实测量值。

## 测试与文件

```powershell
python -m unittest tests -v
```

- `app.py`：HTTP API、SQLite、影像解码、快照、复核与报告。
- `planner.py`：输入校验、专科规则、组件目录、四点角度计算。
- `static/`：无构建步骤、无外部 CDN 的 HTML/CSS/JavaScript 页面。
- `tests.py`：规则、边界、并发、迁移及接口回归测试。
- `变更说明.md`：与旧版的差异。
- `验证记录.md`：本次实际测试结果与验证范围。

当前没有真实器械库、医学影像自动分割、三维手术模拟或生物力学验证。后续可通过接口接入这些能力，不能将本版规则输出用于实际诊断、器械选型或手术决策。
